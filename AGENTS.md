# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## Project

- This is an Android-first Expo SDK 57 application written in TypeScript.
- **Map feature requires Expo Dev Client:** The Map screen uses `react-native-maps`, which is not bundled in Expo Go. Local development now requires an **Expo Dev Client** build (via `npx expo run:android` or `eas build --profile development`). Expo Go is no longer compatible. The `preview`/`production` EAS profiles are unaffected and continue to produce standalone release APKs without Expo Go.
- Use `npx expo install <package>` for Expo and React Native dependencies so versions match the SDK.
- Do not edit generated `android/` or `ios/` folders by hand. They are intentionally ignored and should be regenerated by Expo when needed.
- Keep the `preview` EAS profile producing an installable APK.

## Map screen configuration

- New environment variables (must be set locally in `.env` and via EAS Environment Variables for cloud builds):
  - `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY` — Android Google Maps SDK API key, obtained from Google Cloud Console and restricted by package name + SHA-1 fingerprint.
  - `EXPO_PUBLIC_WEATHER_TILES_API_KEY` — OpenWeatherMap API key for tile layers.
- Never commit real API keys to git. Use placeholders in `.env.example` (committed) and override via `.env` (gitignored).
- Field data (user's own markers/polygons) persists locally via AsyncStorage; "other users' markers" are mocked locally for now, ready for future backend integration via the `FieldsRepository` interface in `src/map/repository/index.ts`.

## Workflow

- Read `SPEC.md` before implementing a feature and update it when requirements change.
- Prefer the smallest solution and avoid new state-management or UI libraries until the app needs them.
- Run `npm run typecheck` after code changes and `npm run check` before a build.
- Do not commit credentials, `.env` files, signing keys, build output, or Expo access tokens.
- Preserve accessibility labels and touch targets for interactive controls.
