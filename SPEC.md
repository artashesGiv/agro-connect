# Спецификация приложения

## Назначение

Базовая заготовка конкурсного Android-приложения. Конкретную идею, аудиторию и основной пользовательский сценарий нужно описать здесь до разработки функций.

## Текущая версия

- Четыре экрана с нижней табовой навигацией:
  - **Главная** — интерактивный счётчик для проверки состояния
  - **Данные** — список элементов с тестовыми данными о конфигурации
  - **Карта** — управление полями агрария: свои метки/полигоны, метки других пользователей, слои погоды
  - **Параметры** — переключатели и информация о приложении
- Полная типизация TypeScript для навигации
- Портретная ориентация и тёмная тема
- **Требует сети** для загрузки тайлов карты и слоёв погоды
- **Требует разрешения на геолокацию** для отображения текущего местоположения на карте (запрашивается при первом открытии вкладки Карта)
- **Требует Expo Dev Client** для локальной разработки (Expo Go больше не поддерживается — используется `react-native-maps`)
- EAS-профили: `preview` создаёт устанавливаемый APK (без Expo Go, включает native map modules), `development` создаёт dev-client для локальной работы, `production` создаёт release-сборку

## Требования, которые нужно уточнить

- Название и задача конкурсного приложения.
- Обязательные экраны и сценарии.
- Версия Android и устройство жюри.
- Допустимость React Native, Expo, сети и внешних API.
- Нужен ли подписанный release APK и есть ли ограничение размера.

## Критерии готовности

- `npm run check` завершается успешно.
- APK (профиль `preview`) устанавливается на чистое физическое Android-устройство.
- Приложение запускается после перезагрузки устройства и без dev-сервера.
- Вкладки Главная/Данные/Параметры работают без сети.
- Вкладка Карта требует сети (для карты и слоёв погоды) и разрешения на геолокацию; центрируется на текущем местоположении либо на регионе по умолчанию (Москва) если разрешение отклонено.
- Локальные поля пользователя сохраняются между перезагрузками приложения (AsyncStorage).
- Маркеры других пользователей отображаются как мок-данные и не редактируются.
- Сбор dev-client (`npx expo run:android` или `eas build --profile development`) требует установленного Android SDK (или EAS CLI для cloud build).
